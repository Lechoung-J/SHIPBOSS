# Verification scripts

Bind each check to a fixed delivery and an explicit file set.
Execute checks in a fresh copy with isolated temporary state.
Record commands and real process exit codes. A nested process failure must propagate.
Keep outputs outside the published source tree.
Run positive behavior tests and negative boundary cases.
Check relative documentation links and launcher targets.
Read comments, fixtures, generated bundles, source maps and archive payloads.
A scanner result supplements human semantic review.
Preserve failures and report untested conditions explicitly.
